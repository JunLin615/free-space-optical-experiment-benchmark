# Two-iris alignment diagnosis

An alignment laser passes through two irises on an optical table. The first iris is
close to the steering mirror; the second is farther downstream. If the beam is
centered on the first iris but displaced at the second, change the steering angle
and then recenter the first iris with a translation adjustment. Repeat because a
single downstream observation cannot separate beam position from beam angle.

This procedure separates position error from angle error by using observations
at two distances.
