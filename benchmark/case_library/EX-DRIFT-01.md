# Reference channel for slow drift

In a free-space transmission measurement, split a small fraction of the input
beam to a reference photodiode before the sample. Normalize the transmitted
reading by the simultaneous reference reading after subtracting both dark
offsets. A synthetic trace with source power drifting by 7% while sample
transmission is fixed can then show a nearly constant normalized ratio. The
method only helps when reference and sample paths share the relevant source
fluctuation; it cannot remove drift introduced after the split.
